# Module 5: Scaling Under Load 📈

Your app just went viral! 🎉 Traffic spikes, and a single Pod can't keep up.

Kubernetes can run more copies of your app, and the Service spreads traffic across them. This is **horizontal scaling**: more copies, not a bigger machine.

In this module you will:
1. Start with a single Pod
2. Send simulated traffic
3. Scale to 5 replicas
4. See load balancing across Pods

> ⏳ The cluster takes a minute to start. Wait for the terminal to be ready.
