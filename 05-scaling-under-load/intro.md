# Module 5: Scaling Under Load 📈

Your app just went viral! 🎉 One Pod can't keep up with the traffic.

Kubernetes can run more copies of your app, and the Service shares traffic between them. This is **horizontal scaling**: more copies, not a bigger machine.

In this module you will:
1. Start with 1 Pod
2. Send simulated traffic
3. Scale to 5 Pods
4. See traffic spread across them

> ⏳ The cluster takes a minute to start. Wait for the terminal.
