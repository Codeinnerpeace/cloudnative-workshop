# 🎉 Module 4 complete!

| Term | Meaning |
|---|---|
| **Service** | a stable address + load balancing for Pods |
| **Selector** | how a Service finds its Pods (by label) |
| **NodePort** | opens a port on every node for outside traffic |

✅ **Works everywhere, check 4:** your app is reachable from a browser, no matter which Pod answers.

> 📚 **Later:** there are other Service types. **ClusterIP** is internal only (the default), and **LoadBalancer** asks a cloud provider for a public address.
